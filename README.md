## 🔵 Reading the Rings

Each ring stands for one session figure. A ring is drawn as a circle of small dots. As the figure grows, more dots fill in. When a ring is mostly empty, that figure is low. When it is mostly full, that figure is high. A ring that is changing is showing you activity in real time.

You do not need to learn any special vocabulary. The rings are meant to be read the way you read a fuel gauge or a clock face: by shape and position rather than by exact value. If you want precision, the rings work alongside the numbers rather than replacing them, so you can look closer whenever you need to.

If two rings look similar in size, that is expected — rings are sized to remain readable rather than to compete with each other. Focus on how full each one is, since that is where the real information lives.
